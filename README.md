# 🛡️ Bobify (Release Readiness Dashboard)

[![Live Demo](https://img.shields.io/badge/Live_Demo-Vercel-black?style=for-the-badge&logo=vercel)](https://bob-release-guard.vercel.app/)

Bobify is a pre-deployment invariant verification gateway. It ensures zero-downtime and safe deployments by simulating four parallel AI agents (Schema, Config, Dependency, and Rollback) to analyze code changes, flag high-risk down-migrations, and enforce human-in-the-loop approvals before anything touches production.

## 🚀 Features

- **4-Parallel Agent Architecture:** Simulates parallel sweeps for Schema, Configuration, Dependency, and Rollback invariants.
- **Interactive UI:** Smooth transitions from Landing -> Scanning -> Dashboard.
- **Rollback Proofing:** Ensures down-migration safety on isolated branches before production merge.
- **Raw Telemetry Viewer:** Inspect the exact JSON output generated by the AI sweeps.

## 💻 Run Locally

**Prerequisites:** Node.js (v18+)

1. Clone this repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open `http://localhost:3000` (or the port specified in terminal) in your browser.

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Framer Motion, Lucide React.
- **Deployment:** Vercel (CI/CD integrated with GitHub)
